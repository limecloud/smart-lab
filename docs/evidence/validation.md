## 引擎与 API 覆盖

[引擎测试](../../tests/engine.test.ts)覆盖设备互斥、资源释放后排队、独立设备并发、优先级、两种默认机器人流程并发完成、竞争后的重新接驳、中断移动从实际位置继续、暂停/恢复/取消、仿真时钟与速率、故障恢复、无导航取放拒绝、流程快照、结果可重复与幂等、状态恢复以及输入校验。

[HTTP 测试](../../tests/http.test.ts)覆盖任务生命周期及错误码、同源写入限制、无效 JSON 与 1 MiB 限制、枚举参数拒绝数组/对象、SSE 初始与后续状态、原子持久化及重启恢复、静态资源托管与路径边界。

[Cloudflare 测试](../../tests/cloudflare.test.ts)覆盖连续恢复移动与资源锁、墙钟补算与重试幂等、暂停/空闲时钟、Cookie 隔离与 HTTPS 属性、API 错误语义、持久化对象重建和 SSE。该部分使用内存 DO 替身与真实引擎；本机 workerd 验收另行覆盖真实边缘运行时。

这些测试验证模拟执行器的状态及数据语义。模拟测量值由确定性规则生成；通过不等于仪器完成过实际检测。

## 浏览器覆盖

[浏览器测试](../../e2e/lab.spec.ts)实际覆盖以下场景；整套九项和新增后的针对性复验分别记录在上表：

1. 三维场景、五个页面和全局仿真控制。
2. 双模型素材、设备热点、图层、缩放与 GIF 预览。
3. 三维场景材质加载、轨道操作与机器人位置随任务变化。
4. 编辑流程、运行实验、查看结果和导出 CSV。
5. 运行任务的暂停、继续和取消。
6. 设备故障导致任务失败，恢复后重试完成。
7. 占用中的设备拒绝切离线，界面显示真实错误。
8. 窄屏导航和数据访问。
9. 三维设备近景、放大工作区、滚轮操作和 Escape 退出；验证 GLB 与 HDR 真实加载。
10. 主动阻断模型请求后的降级提示、解除阻断后的重新加载与恢复。

测试使用 4312 后端与 5175 前端、独立状态文件，不依赖 4311 用户预览服务。REA 单独使用 4313。现有报告是本地浏览器证据，不能替代公网环境、其他浏览器或性能负载测试。
