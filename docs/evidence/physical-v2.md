# 第二版三维场景验收

日期：2026-11-06。对应实现见[三维升级说明](../design/physical-v2.md)。

## 资产与构建

实际执行资产采集、MJCF 视觉层级转换、材质分组、量化与 meshopt 压缩，GLB 从 10,371,324 字节变为 2,079,668 字节。保留七个转动节点、两个滑动夹指；没有导出物理或控制模型。来源固定版本及摘要见[资产记录](../../public/assets/physical/SOURCES.json)。

`npm run build` 通过，包含前端、Node 与 Worker 三套类型检查；Three.js 主包构建有体积提示。模型解码器来自 Three.js，资产来自同源静态目录，没有运行时第三方地址请求。

## 浏览器检查

最终完整浏览器检查 **9/9 通过，约 2.7 分钟**，覆盖任务编排、机器人位置、结果、设备互斥、窄屏及新增的近景工作区。新增场景首次发现近景取景检测误对 Sprite 标签射线查询，导致缺少相机引用的运行异常；将检测集合限定为不透明实体 Mesh 后，针对性复验通过，之后完整九项复验也通过。没有通过移除断言掩盖问题。

新增检查验证：Panda GLB 加载、实拍 HDR 加载、放大工作区面积增大、机器人近景与分析工位切换、滚轮改变相机、Escape 退出、无页面异常。原有场景还验证双素材切换后重载正常与真实后端机器人位置变化。

随后补充模型加载状态和重试提示，针对近景与网络恢复两项复验 **2/2 通过，17.7 秒**。恢复测试主动阻断 GLB 请求，确认降级提示出现，再解除阻断、点击重试，确认精细模型恢复且提示消失。此时测试目录共有十项定义；最近一次整套运行是前述九项，不能把两项针对性复验写成十项整套运行。

## 公网复核

Cloudflare HTTPS 完整任务脚本再次通过。线上 GLB 下载为 2,079,668 字节，实测该次下载约 4.60 秒，SHA-256 与本地产物一致。浏览器第一次等候模型的 30 秒限时未通过；保留这次失败，未把它写成通过。随后采用 60 秒观察窗口实际加载成功，七项纹理、HDR、机械臂、近景与截图均完成，控制台与页面错误为零。单次初次超时原因未被独立确认，不把它归因到确定的 CDN 故障。

本页四张截图已由实际线上地址重新采集；采集脚本不修改系统 DNS，也不关闭 HTTPS 校验。加载失败时的降级与重试另由上述主动网络阻断测试验证。

## 验证范围

当前资产不是对应现场的扫描；机械臂展示动作不是逆运动学或物理仿真。未实测长期帧率、跨所有移动设备的显存使用或真机控制性能。窄屏关闭环境遮蔽，但仍需加载相同机械臂资产。
