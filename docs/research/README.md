# 智能实验室实现研究

本专题面向开发者，研究参考截图中的“AI＋机器人智能实验室”怎样通过软件与设备协作实现，并为 Smart Lab 的控制台、3D 仿真和任务编排提供依据。查证日期：2026-11-06。当前交付阶段为软件演示与仿真，未连接真实机器人或实验仪器。

**核心判断：这类系统由实验工作流、资源调度、移动机器人、机械臂、仪器驱动和数据追溯共同组成。** 网页里的 3D 场景负责显示状态；可靠的任务执行需要独立的后端状态机与设备反馈。AI 可以辅助生成受约束的实验方案和分析结果，但不应把自然语言直接当作机械臂控制指令。[S02][S03][S04][S05]

截图可以确认白色实验设备、两台复合移动机器人，以及“精准化操作”“实验数据自闭环”等展示标签。[S01] 它不能确认原厂采用的协议、导航算法、机械臂品牌、软件架构或真实性能。此次未获得可确认的 HintonAI 原厂软件发布包，不能宣称恢复原厂代码；REA 的具体分析对象、Evidence 与限制应以项目独立的 REA 报告为准。

## 项目与资料的关系

本项目选择浏览器 3D、后端仿真与任务状态机来验证用户操作和业务流程。文中提到的 ROS 2、Nav2、MoveIt、Open-RMF、SiLA 和 PyLabRobot 是后续真实系统的技术路线参照，**不代表它们均已安装或已被本项目集成**。若后续获得设备型号和接口文档，应优先复用厂商支持的驱动，在适配层逐台验证，而不是根据外观猜协议。
