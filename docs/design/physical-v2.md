# 第二版三维设备与实拍材质

本轮升级将“完整照片贴在设备正面”的主要表现改成有结构的三维设备，保留图片参考模式与任务状态源。不是对原图实物的精确测量重建。

## 本次实现

- 机械臂使用 MuJoCo Menagerie 公开的 Franka Emika Panda 视觉网格，保留七个转动关节及两指夹爪；显示为 GLB，用任务步骤驱动展示姿态。该型号是有许可的视觉参考，不表示原图或现场使用此机器人。
- 移动底盘重新制作圆角外壳、包边、保险杠、传感器、车轮、轮毂、通风口、紧固件、急停、线缆和样品托盘；轮子随位移转动。底盘和工位均为本项目参考设计。
- 自动分析仪包含玻璃门、门框、内腔、样品试管、导轨、移液头、供电线、通风口、抽屉、工作站屏幕和脚垫。它的内腔、侧面与后板都具有几何，不用整张仪器照片代替。
- 通风柜、准备台、存储站和墙体同步增加结构与材质细节，房间增加窗框、百叶、供电与走线；地面取消棋盘网格，保留接驳标记。
- 地面使用 Poly Haven 实拍图像派生的颜色纹理，搭配法线和粗糙度图；颜色经过降饱和、降低对比和树脂地坪色调处理。HDR 环境来自 Poly Haven 的实拍 Studio Small 09，用于反射与环境照明。它们都不是该实验室现场采集资料。
- 材质区分喷漆、金属、橡胶、玻璃和屏幕，增加屏幕空间环境遮蔽与多重采样抗锯齿。窄屏关闭环境遮蔽，减少渲染负担。

保留 Flare / Sunburst 已生成素材作为图片参考和小面积局部细节；没有为本轮再次生成图片，也没有以 AI 图像冒充实拍设备照片。

## 操作

场景顶部可选择“全景”“机器人近景”“分析工位”。机器人近景会从四个方向检查其他设备遮挡并选择候选角度；这是取景辅助，不是完整相机避障系统。镜头选择完成后仍可自由旋转、平移和滚轮缩放。

左下角放大按钮将三维工作区铺满窗口；再次点击或按 Escape 退出。设备选择、轨迹图层、协同任务和暂停控制继续使用同一后端状态。

## 资产、许可与复现

[资产来源与摘要](../../public/assets/physical/SOURCES.json)固定了来源版本、文件 URL 和 SHA-256。[NOTICE](../../public/assets/physical/NOTICE.txt)记录修改与署名；Apache-2.0 与 CC0 许可全文随资产分发。

机械臂源数据固定到 Menagerie 提交 `98a70c569c4c1b6da467a20012f766ee1f8dc521`。转换后每机械臂约 13.5 万三角面、25 个材质绘制组。GLB 从 10,371,324 字节压缩到 2,079,668 字节，采用量化与 meshopt 压缩，没有设置三角面简化。两个机器人共享加载后的几何资源；静态零件按材质合并，关节与车轮独立保留。

预生成 GLB 和纹理已随项目保存，运行和正常构建无需重新联网采集。要重建：

```bash
uv run --no-project --with pillow python "scripts/prepare-lab-assets.py"
node "scripts/build-panda-model.mjs"
npm run build
```

源 OBJ 与 MJCF 缓存在 `node_modules/.cache/smart-lab-assets`，不进入发布产物。构建工具只作为开发依赖，浏览器使用 Three.js 自带 meshopt 解码器。

截图复核可运行：

```bash
node "scripts/capture-scene.mjs" http://127.0.0.1:4311
```

## 仍然存在的边界

机械臂展示动作不包含逆运动学、真实轨迹、抓取接触解算或碰撞规划。房间与仪器依据视觉和参考尺寸制作，并非现场扫描，也没有实际设备的精确 CAD。透明与反射为实时近似；HDR 是摄影棚采集，不代表现场光照。当前不宣称达到实拍不可区分或任意视角的精确数字孪生。

未来取得对应设备的 CAD、多角度照片和标定尺寸后，可替换同一设备节点，继续复用现有交互与任务状态，无需重写业务调度器。摄影测量与 3DGS 的适用边界见[真实性分析](photorealism.md)。
