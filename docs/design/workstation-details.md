# 电脑工位与近景细节

本轮针对电脑外观、外设和支撑结构重新建模，保留自由旋转、平移、缩放、设备点选与任务驱动动作。两个电脑工位复用同一模块，无新增运行依赖或外部图片请求。

## 实现

- 显示器采用约 24 英寸、16:9 的参考尺寸，包含薄边框、独立后盖、通风孔、VESA 固定板与螺钉、俯仰铰链、支架、穿线扣、金属底座和橡胶脚垫。
- 屏幕为单面平面与独立 Canvas 纹理，背面显示外壳、接口与序列标签。屏幕展示后端实际设备状态、关联任务、当前步骤、进度与仿真暂停状态，不生成虚构测量曲线。
- 全尺寸键盘包含独立键帽、字符、功能区、方向区、数字区与指示灯。键帽文字共用图集；静态几何沿用同材质合并，避免每个按键产生单独绘制调用。
- 鼠标包含弧面壳体、分离按键、滚轮、鼠标垫及数据线。工控主机包含散热槽、按钮、指示灯、USB/显示接口与电源连接；桌下主机有独立托架。
- 分析仪旁补齐独立桌面、桌架、横梁、脚垫、线槽与排插，线缆连接至穿线孔、主机和仪器侧供电接口。准备台使用台面小主机及排插，避免将同一桌下结构穿入抽屉柜。
- 分析仪侧面增加独立检修板、接缝、固定螺钉、通风槽和服务标签。设备铭牌改为单面文字，侧面和背面不再重复整张标签。

外壳材质区分哑光塑料、橡胶、喷漆和金属。没有用新增照片遮盖原来的三维结构；本轮几何与 Canvas 纹理为项目原创参考设计，既有模型和摄影资产许可不变。

## 使用与维护

场景顶部新增“电脑工位”和“电脑背部”，左下角可放大工作区；取景后仍可自由操作。最小相机距离缩短至 0.7 米以支持查看键帽和接口。

[workstation.ts](../../src/scene/workstation.ts)负责电脑建模与屏幕绘制；[geometry.ts](../../src/scene/geometry.ts)复用现有几何原语，避免工位与设备模型之间形成运行时循环依赖。屏幕仅在状态内容改变时更新纹理，不在每帧重新绘制画布。业务调度器、API 和数据存储合同均未修改。

实际截图与测试见[验收记录](../evidence/workstation-details.md)。当前尺寸为合理参考值，未取得原图对应电脑的 CAD、铭牌和多视角照片，不声明为该型号的精确重建。
