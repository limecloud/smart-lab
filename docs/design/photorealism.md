# 从交互仿真走向接近实拍的三维场景

**可以同时获得可交互与更写实的效果，但核心投入应转向可靠的三维资产、材质和现场采集。** 继续给简化盒子贴一张生成图，无法解决轮廓、侧面、关节、反射和视角一致性。当前版本适合验证控制与任务流程；面向真实设备的视觉复刻，应优先制作一台完整的可动机器人和一个有代表性的仪器，再扩展整个实验室。

本文将当前代码观察、公开资料和建议路线分开。AI 生成图片不是实拍；生成出的背面也不是对不可见面的测量或恢复。

## 当前版本为什么仍有模型感

本页最初记录的是单面贴图版的原因分析。第二版已接入公开机械臂 GLB、立体仪器内腔、实拍地面 PBR 和 HDR 环境，并增加近景检查，见[第二版实现](physical-v2.md)。下述关于整张设备照片贴在平面上的说明对应升级前的实现；当前仪器正面已由三维结构替换。

[LabScene.tsx](../../src/LabScene.tsx)中的设备由盒体、圆柱、球体与平面组合。它确实处于三维空间，支持轨道相机、设备选择、底盘移动和机械臂层级动画。材质采用 `MeshStandardMaterial`，已有环境光照、阴影、色调映射和颜色空间设置。

当前生成贴图主要通过 `loadSurface` 放在模型表面的平面上，并不是完整设备的 UV 展开与多通道 PBR 材质。机器人正面、通风柜、分析仪和存储站的图像可以增加正面细节，却不会改变侧面、开口、倒角、线缆和接缝的真实几何。照片式图像里的透视和阴影已被画进颜色，重新从另一个角度照明时可能形成重复阴影或不一致的高光。

[TwinScene.tsx](../../src/TwinScene.tsx)的固定相机“写实参考”模式采用环境图和投影到画面的机器人图层。这个模式能快速得到一致的正面画面，缺少任意视角的几何和完整遮挡。它与可旋转的几何场景承担不同用途。

因此，当前技术难点不只是提高图片分辨率，还包括：

| 问题 | 需要解决的内容 |
| --- | --- |
| 轮廓不像真实设备 | 比例、倒角、门缝、脚轮、机械臂关节和末端夹具的几何 |
| 换角度就露出贴片感 | 所有可见面的几何与 UV、一致的多角度外观 |
| 白色塑料与金属像同一种材料 | 分开设置基色、粗糙度、金属度、法线与必要的透明/透射参数 |
| 机器人动起来不真实 | 关节轴心、父子层级、运动限位、轮子与夹具动作、与台面的接触关系 |
| 现场空间缺少真实感 | 相机标定、尺寸比例、现场照明、软阴影、接触阴影和背景细节 |
| 视觉接近但不能可靠交互 | 稳定设备 ID、选择代理、遮挡代理与服务端状态绑定 |

这些问题需要共同处理。仅调高反射、曝光或阴影，不能补出缺失的模型结构。

## 三条资产路线

| 路线 | 适用对象 | 优点 | 主要限制 |
| --- | --- | --- | --- |
| CAD/人工建模 → GLB → PBR | 需要移动、转动、开门、抓取或精确选择的机器人与仪器 | 尺寸和部件层级可控，便于状态绑定、遮挡与动画 | 需要取得可用模型或建模；CAD 还需减面、清理内部零件与制作材质 |
| 多视图摄影测量 → 网格与贴图 | 静态、纹理丰富、可从多角度拍摄的空间和设备外壳 | 能保留现场磨损、颜色和形态 | 白色无纹理表面、玻璃、金属反光和遮挡会降低重建质量；可动关节通常仍需拆分重建 |
| 多视图采集 → 3D Gaussian Splatting＋代理几何 | 主要作为真实现场背景的静态空间 | 擅长在采集视角覆盖内表现现场外观与新视图 | 不是天然可用的CAD/碰撞模型；编辑、动态对象、视角外区域与混合遮挡需要额外工程 |

第一条适合作为本项目的首选升级。第二、三条都需要真实多视图资料；目前只有一张参考截图和生成图，没有足够输入完成忠实现场重建。[P01][P03][P04]

### 可交互设备：CAD/GLB 与关节层级

建议先取得厂家可用的 STEP、FBX、glTF/GLB 或人工制作模型。将可动零件保留为独立节点：底盘、轮子、机械臂各连杆、末端法兰、夹爪、门和样品托盘。节点轴心、单位与坐标约定必须先统一；不应把整条机械臂合成一个不可拆的网格。

glTF 的节点有层级与局部变换，PBR 使用 metallic-roughness 模型，可以携带基色及材质贴图。[P01] 对刚性机械连杆通常采用父子节点变换即可，不必为了动画增加不需要的柔性蒙皮。真实关节轨迹未来可以驱动相同节点；当前演示动画仍需标为仿真，不能视为逆运动学或轨迹规划结果。

材质应按塑料、喷漆金属、裸露金属、橡胶和玻璃分组。颜色贴图表达表面颜色，粗糙度/金属度控制反射响应，法线贴图补小尺度表面细节。Three.js 官方说明 `MeshStandardMaterial` 使用 metallic-roughness，并建议结合环境贴图获得更好的效果。[P02] 但使用 PBR 材质类本身不保证写实，仍依赖正确资产、参数、灯光与相机。

### 静态现场：摄影测量

COLMAP 官方教程将 Structure-from-Motion 描述为从同一对象的重叠、多视点图像重建结构与相机参数，后续多视图立体可生成深度、点云、网格和纹理。[P03]

采集应覆盖不同位置与高度，并保持足够重叠、稳定照明和清晰细节。只站在一个点旋转相机不等于获得足够多视角。官方也明确提醒无纹理区域和高反光表面的问题。[P03] 实验室常见的白柜、玻璃、镜面金属恰好是难点；必要时采用人工几何、合规可移除的标记或经允许的表面处理，不能把缺陷区域直接当成可靠测量。

对仪器内部、背面和柜体之后的不可见区域，应补拍或按尺寸建模，并标记来源。由单张图推测出的区域是设计补全，不是恢复出的事实。

### 静态背景：3DGS 与代理几何混合

3DGS 原始项目用多照片/视频与相机标定得到的稀疏点优化三维高斯，并进行可见性感知的 splatting，用于新视图合成。[P04] 它保留的是一类用于渲染的场景表示，不会自动得到适合设备关节、CAD 编辑或碰撞检测的完整实体模型。

一个务实的候选方案是：静态墙体、地面和非交互设施使用现场 3DGS 背景；需要移动和操作的机器人、仪器门、样品使用 GLB/PBR；另建低复杂度代理几何处理点选、深度遮挡与空间约束。这是**建议路线，当前项目尚未集成 3DGS**。

需要特别处理以下问题：

- 采集中的机器人、人员和门运动会使“一个固定场景”的解释不一致；应清场、分离对象或采用专门的动态重建方案。
- 玻璃、透明容器和反射金属的外观随视角变化，不能把颜色重建等同于正确的材质和表面。摄影测量官方已明确提醒反光问题；在混合渲染里还需实测透明排序、深度与反射的一致性。[P03]
- 采集视角没有覆盖的背面和区域，可能出现空洞、漂浮点或外观退化；不能承诺自由飞到任何地方都与现场一致。
- 静态背景中若保留原机器人，再叠加可动机器人会出现“两个机器人”或残影，需要在采集或处理阶段分离动态对象。
- GLB 与高斯场景需要共同坐标、尺度和深度合成；代理几何必须与真实布局校准。图像看起来接近，不足以证明空间可用于安全控制。

这些限制是对本场景的工程判断，不是已经运行的 3DGS 测试结果；原论文的帧率和质量不能直接搬作本项目承诺。

## 建议实施顺序与验收方式

1. **先做一个完整设备。** 选 AMR-01，取得或制作有正确轮廓、侧面与关节的 GLB；在前、侧、后及俯视角检查，明确哪些尺寸来自实测、厂家模型或参考设计。
2. **建立材质和照明基线。** 在一致的环境光、相机和曝光下调塑料/金属/橡胶/玻璃；比较固定角度照片或经确认的渲染参考，避免用单张带阴影图片代替所有材质。
3. **接回现有状态与动作。** 保留设备 ID、选中、位置、暂停和任务状态链；只替换模型层。机械臂动作先验证轴心和接触，再决定是否接入真实轨迹。
4. **做一个真实工位。** 补齐一个分析仪或通风柜的外观、开口、台面和取放点，验证机器人接近、遮挡、标签与交互。之后再批量扩展其他设备。
5. **按需要增加现场重建。** 有现场采集条件时比较摄影测量与 3DGS 小样，检查白色柜体、玻璃、反射、窄通道和移动对象；确认混合深度及加载成本后再覆盖整个空间。

验收应至少检查多个固定视角与交互视角、运动中的遮挡和接触、目标浏览器的加载/帧率/显存表现、窄屏降级，以及模型替换后任务流程仍然正确。性能指标应在明确设备和画质配置上实测，本次不虚构帧率或制作工期。

如果暂时没有实物资料，可以采购授权合适的资产或按公开尺寸制作“类似设备”的模型，达到专业可视化质量；应将其称为参考设计，不宣称是原厂设备的精确数字孪生。AI 生成素材适合作为概念和材质参考，不能替代设备结构、材质测量和多角度事实。
